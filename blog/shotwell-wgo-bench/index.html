Shotwell-WGO-Bench: An annotation benchmark that accepts valid alternatives

TL;DR: Shotwell-WGO-Bench assesses how well models segment and describe video. It improves WGO-Bench's scoring - which penalizes valid annotations because it scores against a single reference annotation - by providing multiple references that together accept all correct ways to annotate a clip.

VLMs are a practical way to produce dense language annotations for the large amounts of egocentric video used in robot-policy pretraining. There are several existing benchmarks that assess VLM annotation accuracy that are flawed because they penalize annotations that differ from the benchmark's reference set but are still valid annotations. Shotwell-WGO-Bench builds on WGO-Bench by assessing accuracy in producing annotations without penalizing different valid ways of segmenting the same video.

An annotation divides an episode into actions and describes each action in language. The tradeoffs between VLM approaches are accuracy, level of detail, and cost. Accuracy is particularly difficult to benchmark: annotators can choose different boundaries or group actions differently, yet produce equally valid accounts of what happened.

How we align annotation for better scoring

Shotwell-WGO-Bench reduces these arbitrary penalties by restructuring WGO-Bench in four ways:

  1. An extremely detailed annotation guide. It specifies which actions merit their own segment, exactly where boundaries should fall, and the format and level of detail expected in each description. This makes model outputs very consistent before grading begins. Shotwell-WGO-Bench also demands a much higher level of detail in outputs that spotlights the limits of weaker models.
  2. Multiple acceptable segmentations. Even with a precise guide, there is a range of timestamps where an action boundary can be placed, and some actions can reasonably be grouped or split. The reference annotations include acceptable ranges for each individual boundary, rather than one fixed tolerance for every boundary. They also include optional sub-boundaries where splitting an action is valid. Every valid possible segmentation logic for an episode is captured.
  3. Multiple acceptable descriptions. For description grading, models receive fixed segments to describe. Each reference description provides required details and optional details for each segment. An LLM judge checks that every required action is present with the right verb, object, and hands. It allows compatible specificity and slight generalizations, but rejects contradictions and independent actions without reference support. The guide and explicit reference details leave less to the LLM judge's discretion.
  4. Curated episodes with clearer actions. We select clips where action boundaries and descriptions can be judged with relatively little ambiguity, limiting cases where equally careful annotators would disagree.

The limits of a single reference timeline

WGO-Bench and MicroAnnotationBench compare VLM annotations with human reference annotations. Both compare segmentation against just a single reference timeline. This can penalize logical alternative groupings of actions and understate annotation quality. Astra scores around 0.40 F1 score in published evaluations of both benchmarks. Results

We calculate segmentation and description F1 separately, then multiply them for the final score. Each model is evaluated at 8 frames per second on the episodes in the chart.

Here, the capabilities of stronger models, and the gap between them and weaker models, are shown much more strongly than in the original WGO-Bench. In the original benchmark, smaller models that were clearly weaker (such as FLORA) scored close to Astra and beat Sol due to the noisiness of the scoring approach. Shotwell-WGO results correlate much more strongly with the generally accepted visual abilities of these models.
